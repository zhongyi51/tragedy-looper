# 开发与验证报告

本文件汇总各版本的验证结果。随机模拟和有限的真实模型对局不是规则正确性或平衡性的证明；正式发行前仍需独立玩家评审。

## 当前自动化

`node scripts/test-all.mjs` 自动启动隔离服务和临时数据库，不读取用户密钥、不调用真实模型：**160 项全部通过**。

- 规则：FS/BTX 共 500 局固定种子随机整局、114 种主副规则配役、24 人物候选能力、移动合成、暗跃禁止抵消、护卫与不死、朋友揭示、最后的战斗逐人指认等情景。
- 可见性：主人公/公开视角不含秘密配役、事件名称及犯人；公开回放、打印、AI 输入使用同一边界；旧存档读取时脱敏。主人公局势简报在替换全部秘密后保持不变。
- AI：只接受合法候选编号；输出容忍代码块与杂讯但只接受 JSON 对象；结构错误最多修复一次；预算不足不发请求；网络不确定保留预留且不重试；剧作家理由不返回客户端。
- 离线机器人：60 个剧本整局每步都是合法命令，双方都有胜局。200 局基线：剧作家 136、主人公 64。
- 界面（直接导入 `public/js` 模块）：牌背不泄露牌面、自己盖的牌只有自己可读、主人公 / 观战视图不出现秘密角色与犯人、选牌后的合法目标与效果预告、回合提示与主按钮、揭示先于移动的演出顺序、减少动态效果时跳过演出、自动对手的停止条件、不确定提交只读不重发、终局 / 轮回横幅、逐条结算播放（每帧一条结果、高亮对象、日结束停顿、跳过、观战自动继续、切换页面时取消）、推理表（规则组合枚举、自动排除、推论、矛盾提示、最后的战斗标注）、工坊表单编辑、离线回放可独立执行。
- 接口与托管：席位权限、跨会话/跨身份访问、幂等提交与并发租约、确定性自动结算不调用模型、整链事务回滚、HTML 网关/登录重定向/损坏 JSON 的恢复。

## 各版本修复要点

- v0.1：模型非法动作改为候选编号加一次修复；公开导出默认 public 视角；友好拒绝不提前泄露；离线回放转义；动作相等改为语义比较；大人物领地强制能力。
- v0.2：400 局随机整局；剧本与回放导入校验；本地与云端并发提交只推进一次；建局防重复、回放滑块焦点、分支存档等界面修复与动效。
- v0.2.1：隐藏事件日程名称（本站约定）；地点佯动合法化（原作者 FAQ Ca01/Ca02）；实体盖牌与统一翻牌；旧 AI 笔记迁移。
- v0.2.2：接口响应先检查状态与内容类型；不确定的行动只读恢复、不重发付费请求；确定性规则步骤一次提交内连续结算。
- v0.2.2 后：模型 JSON 容错；按席位局势简报；更强的离线机器人；自动对手、选择面板、轮回演出、真相揭晓、玩法指南。
- v0.3 后：引擎为每条结算结果记录一帧（含日结束、被禁止的效果）；界面逐条播放并在每天结束时等待玩家；推理表重做；界面文案精简。
- v0.3 后（二）：每条记录带发生的阶段；轮回失败记录失败的时间与公开事实；暗跃禁止互相抵消、禁止被无视单独成条；无效的牌保留划掉的牌面；禁止印记与胜负演出。
- v0.3：前端重写为 ES 模块与全视口棋盘；AI 剧作家三张牌一次决策；机器人组合前瞻；本机与托管共用对局推进逻辑；最后的战斗清空当日盖牌；存档摘要；可视化剧本工坊。

## 已知边界

没有远程多人大厅、语音或轮回间 AI 讨论；生成器保证结构合法，不保证平衡。打印交付为可打印 HTML。托管数据库以 SQLite 模拟 D1 SQL，真实部署仍需确认平台登录、迁移和真实 API 调用。
