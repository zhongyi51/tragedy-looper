## DeepSeek 真实 API 整局测试

用户指定官方服务；调用模型名称为 `deepseek-flash`，当前官方对应 V4.1 Flash。非思考模式、JSON 输出、合法候选编号选择。以下均为真实接口返回用量，金额由应用保守费率计算，不是直接读取供应商账单。

| 项目 | FS 教学局 | BTX 生成局 |
| --- | ---: | ---: |
| 游戏决策数 | 41 | 132 |
| 实际 API 请求数 | 26 | 93 |
| 输入 tokens | 238,370 | 1,045,711 |
| 其中缓存命中 tokens | 119,936 | 494,464 |
| 输出 tokens | 1,803 | 7,156 |
| 应用估算 USD | 0.038413416 | 0.176928084 |
| 结果 | 主人公第1轮回获胜 | 主人公第2轮回获胜 |
| 中断/非法执行 | 0 / 0 | 0 / 0 |

单一合法候选由引擎直接处理，因而决策数大于 API 请求数。请求使用固定规则前缀；总输入已包含缓存输入，不能再把缓存 tokens 加到输入上。完整原始用量见工作目录 reports/live-FS.json 和 live-BTX.json；分发包保留汇总，排除本机游戏数据库。

两局只能证明双方代理、流程、用量记录与错误控制链路实际跑通，不能证明模型强度、剧本均衡或统计胜率。BTX 实战在第二轮回成功生存，未进入最终战斗；最终战斗由自动化情景验证。

包括先前调试、界面调用和剧本润色，本轮开发共记录 152 次已完成 API 响应，应用估算合计约 $0.264。上表两局为最终实现的完整对战样本，合计约 $0.215。

## 本轮发现并修复

1. 初次真实模型测试在第三次出牌给出不合法动作：引擎拒绝、局面未改变。改为编号候选并最多一次修复，后续两局均完整结束。
2. 公开导出原先随剧作家视角走：改为始终默认 public，完整答案需要明确选择且经过权限校验。
3. 不同友好拒绝类型可能从等待阶段提前泄露：所有请求都经过同一确认阶段；主动调用用量在终局前隐藏。
4. 离线回放生成 HTML 时换行转义错误：增加独立脚本编译测试并修复。
5. JSON 属性顺序影响动作相等判断：改为字段语义比较，记录规范化合法命令。
6. 补全大人物在领地发动强制能力的选择；同时处理强制死亡，避免实体数组顺序改变结果。

## 已知产品边界

当前是本地开发版。没有远程多人大厅、账号部署、自动语音或轮回间 AI 讨论；生成器保证结构合法，AI目前润色故事，不保证平衡或求解证明。打印交付为可打印 HTML，非内置 PDF 引擎。普通回放采用观察快照，旧版仍能只读播放；没有自动重新执行任意旧版本内核。比赛级时间侧信道防护和独立规则复审仍需另行验证。
