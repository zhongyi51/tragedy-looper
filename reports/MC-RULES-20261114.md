# Mystery Circle（MC）实现与独立审计规格

研究日期：2026-11-14。用途：项目内部实现和回归测试。本文描述游戏机制，不复刻规则书叙述。

## 采用的规则口径

本次统一按原作者日文官方 `summary_002.pdf`（文件标题为 **Mystery Circle**）以及现行通用裁定实现；与项目已有日文 5th 人物、MZ 基线一致。英文 Midnight Circle 盒内的 MC 作为对照来源。产品仍标记 `MC / Mystery Circle`，不另造 `MCX` 规则集。

必须保留来源事实：官方现行目录将此下载归在 **Mystery Circle Χ** 项下，故“PDF 标题无 Χ”本身不能证明下载的是 2012 初版。英文 MC 和当前日文表的规则名单一致。本实现的准确描述是“采用原作者公开 MC 速览与现行裁定”，不要声称逐字复刻某一印次的英文盒规则，也不要称完整覆盖所有 Midnight Circle 人物包。

## 集合与剧本构造

- 选 1 个规则 Y、2 个不同规则 X，共 `5 × C(7,2) = 105` 种合法组合。
- 正常最后的战斗，没有 MZ 的伪装声明或临时身份替换。MC 本身的 EX 卡不改变身份。
- 角色配额按 Y/X 合并，受身份最大数量限制：`fool:1`、`misleader:1`、`friend:2`，其余无身份上限。超过上限的条目截到上限，不应把此 Y/X 组合判非法。
- `fool`、`twin`、`obstinate` 必须各为至少一个事件的犯人；`private_investigator` 不得当犯人。
- 一个人可以负责多个 `serial_murder`，但不可以因此兼任另一个不同种类事件的犯人。其余事件遵循一人一事件。没有要求每种事件都出现。
- 现有人物限制继续生效（如 Irregular 的非选定规则身份、Boss 领地等），不要把人物能力或 AI 的模拟选择算进剧本犯人配额。
- 按用户设定保留隐藏/公开日程两种模式；它们属于网页版玩法设置。标准规则的公开表包含日期和名称而不包含犯人。

## 全部身份

下表的“同区”默认指在场生存人物；尸体不是普通人物目标。事件和强制能力只公开可见结果，不自动揭示其来源或原因。

| id | 拒绝 | 阶段与机制 |
| --- | --- | --- |
| `key_person` | 无 | 自身死亡导致主人公败、立即结束轮回。主人公不死不能抵消这种败北。 |
| `brain` | 任意 | 剧作家能力：可在同区人物或自身所在地区放1暗跃。 |
| `killer` | 任意 | 日末任意：同区关键人物暗跃≥2可杀该人物；自身暗跃≥4可杀主人公。 |
| `misleader` | 无 | 剧作家能力：可给同区人物1不安。上限1。 |
| `serial_killer` | 无 | 日末强制：同区恰有1个其他人物时杀其；按同一强制时机快照判断，不根据别人的同时死亡补触发。 |
| `friend` | 无 | 轮回末若是尸体则公开其身份并败；身份曾公开则下一轮起获得1友好。上限2。 |
| `obstinate` | 强制 | 必须犯人；在场生存即不看不安阈值而触发自身事件。但 Suppression 等不能发生的效果优先。 |
| `poisoner` | 任意 | 日末强制：EX≥2时杀同区任意1人，每轮1次；可选择自己。EX≥4时强制杀主人公。两者同时间触发，不能先自杀抹掉后一项。 |
| `fool` | 无 | 必须犯人，上限1。其实际事件结算后清除自身（或尸体）全部不安；不清暗跃/友好。Portent 先增再清；AI模拟不触发此身份能力。 |
| `private_investigator` | 无 | 不能犯人；不死；EX=0时若同区有在场生存犯人，那个事件无需足够不安即可触发；仍受不能发生的效果约束。 |
| `paranoiac` | 强制 | 剧作家能力：可给自己1暗跃或1不安，每日任择其一；不是两项可各做一次。 |
| `therapist` | 无 | 剧作家强制能力：EX≥1时从同区其他1人移除1不安。可选0不安目标，从而无可见结果。无其他目标则无效果。强制先于任意能力。 |
| `twin` | 无 | 必须犯人。其实际事件的整个解决期间，其所在地区视为原地区对角；不改变实际棋盘位置，不改变发生判定位置。AI模拟不触发此替换。 |

### 必须避免的角色实现错误

- Poisoner 对不死人物合法，能力用过即消耗每轮一次，即使死亡被护卫/不死阻止。不能以“目标未死亡”重开可用次数。S3 Ch17、18。
- 多个日末强制效果在同一时机判断并同时解决。队列可以是程序实现，但不能让前项杀死来源抹掉已经触发的后项。快照中有3人的 Serial Killer 不会因同一批 Poisoner 杀掉一人变为2人而新触发。S9。
- Fool 事件杀死关键人物或主人公时，清不安与立即轮回结束同时进行，主人公必须看得到清零结果。S3 2013-07-04。不能让 `kill()` 提前退出而丢掉清零。
- Therapist 不应日志“某人发动心理医生能力”，零计数选择更不得输出角色动作线索。作者 https://twitter.com/BakaFire/status/343007770959814656 。
- Private Investigator 未登场时不影响事件。https://twitter.com/BakaFire/status/330153977301839872 。
- Boss 作为 Private Investigator 可选择按领地作用；必须仍为一次普通事件检查边界，主人公响应不可由有无选择泄漏身份。作者 https://twitter.com/BakaFire/status/332483852251570179 。
- Boss 的 Obstinate/Private Investigator 仅作用发生判定，不能改变事件解决地点；Boss 的 Twin 可选择以领地为基础取对角。https://twitter.com/BakaFire/status/332542893350846464 。
- Twin 的虚拟地点也适用于自身被事件影响：Portent 可选择自己；Terrorism/Hospital 全区死亡集合按虚拟位置判断其自身；Serial Murder 仍禁止选择犯人本人。不要只有目标列表换地点而自身效应继续用实际位置。

## EX 与轮回生命周期

1. 新轮回移除所有 EX 卡，并重置伪装自杀的全局卡锁。
2. EX gauge 重置0；按 isolated_psycho 和上一轮最终值决定是否变1。
3. 实际事件一旦确认发生就记发生、公开名称（受所选日程显示模式控制）、增加 EX；是否有目标、是否造成效果不影响计数。一般+1，Bestial +2，Silver Bullet +0。
4. 人工智能只结算效果，不登记真实事件发生，不消耗该日实际事件，不增加 EX，不触发 Fool/Twin 的实际事件能力。
5. 黑猫抹除该事件全部效果与事件修饰：Bestial 不安阈值不+1、EX不替换为2，因此按黑猫基本阈值0触发并正常EX+1。Closed Circle 不公开地区也不锁区；Silver Bullet 不能提前结束，按通用实际事件规则EX+1。关于黑猫 Bestial 的作者原答 https://twitter.com/BakaFire/status/764021454044139520 仅直接明确修饰消失；+1 是通用规则推导。
6. 各类轮回末败北条件照常检查；EX值是公共信息，不额外公开“哪个规则导致失败”。死 Friend 必须揭示。提前 Silver Bullet 也要走同一轮回末逻辑和最后战斗。

Closed Circle 的 AI 模拟也产生完整三天锁区，虽然不是事件发生。作者 https://twitter.com/BakaFire/status/861949309536804864 。全手段移动禁止见 https://twitter.com/BakaFire/status/707944450358534144 。

Suspicious Letter 选原地区不算实际换区，不产生次日锁；可以只公开“事件发生，但没有效果”，不能暴露选择的人物。作者 https://twitter.com/BakaFire/status/707944528490004482 ；隐藏选择的确认在 S7 引用的问答线程。

Bestial 实际事件后半目标需要按第一杀人效果后的存活人物重新确定。AI 必须在是否拒绝前完整声明两个子效果的目标，其候选只能依赖公开信息：允许预声明当前活人组合，不根据秘密身份过滤。执行后半时，若预声明目标已经死亡，则该部分计数效果不施加于尸体，另一合法目标仍正常解决；不死/护卫使其存活则可照常受效果。即使第一目标为关键人物而将导致立即终局，也不能通过预声明候选数暴露该身份。该做法是“目标预声明、尸体不再是人物目标”两条原则的组合推导，未找到专门 Bestial/AI 裁定。

Twin 的 Letter 以自己为目标、目的地等于物理原位置时：按实际棋盘 from/to 判断是否换区，虚拟对角本身不产生实体移动和锁。此角落情形没有找到专门裁定，属于实现采用的解释；同区目标选择仍使用 Twin 的虚拟位置。不能把这条解释声称为已取得的作者直接回答。

## 宣告、隐藏信息与现有系统集成

- 公共：EX值、EX卡、实际位置与计数/尸体、已揭示身份/犯人/规则、可见移动锁区、实际发生的事件名称（以及公开日程配置）。
- 秘密：未揭示配役、犯人、Y/X、能力来源、Boss 是否利用秘密角色触发、被无效化的秘密动作、选同位置而无效的 Suspicious Letter 目标。
- Forbidden/Guard/Immortal 的公开结果不应额外说明秘密身份；“无人死亡”即可，不应输出“侦探免死”。
- Twin 不直接移动卡片，日志不可打印其虚拟移动或“因为双胞胎”。公开事件效果本身可能帮助推理是合法信息；API直接泄漏原因不是。
- MC 没有 MZ 伪装声明，身份揭示可以作为真实身份记录；正确的身份配额推理可以开启。
- AI 模拟沿用已实现“先选择事件→声明完整目标→剧作家决定拒绝→结算”的流程。隐藏日程只揭示主动选择的一天，不一次性输出所有事件选项。
- MC 的 `incident_check`、强制能力选目标等控制边界不能仅在特定秘密身份存在时才暴露给主人公；沿用 MZ 为处理时间和自动推进建立的公共边界。
- 保存/恢复必须持久化前轮EX、当轮EX、区域锁到期日、人物次日锁、Silver当前阶段终局标记、强制能力快照/待选目标、Poisoner使用次数，不能只存动画或局部变量。

## 验证清单

### 确定性规则测试

1. 105组合全部生成合法剧本；fool/misleader裁到1、friend裁到2；三种强制犯人角色存在事件、侦探永不犯人。
2. BlackSchool loop1 school0败；loop2 school0胜/school1败；loop3 school1胜/school2败。
3. Tightrope EX1败/2胜；Quilt EX2胜/3败；Smell仅活人和在场合计11/12边界。
4. isolated首轮0；前轮2→下一轮1，前轮3→下一轮0；不是累积加到前轮EX。
5. Portent limit2的犯人paranoia1触发；Bestial同人物paranoia2不触发/3触发；黑猫Bestial threshold0、EX+1。
6. Strychnine只改变SerialMurder/Suicide；Portent/Bestial不吃暗跃；AI暗跃不重复算。
7. 侦探EX0同区强制发生、EX1不强制；不在场侦探不强制；suppression胜过侦探/obstinate。
8. Twin实际学校、虚拟医院：触发用学校，杀人/Portent目标用医院；自身可作Portent目标；Terrorism/Hospital按虚拟位置影响自身；board.location仍学校。
9. AI Twin模拟按AI实际区，无虚拟对角；Fool AI模拟不清不安、不记occurred、不加EX。
10. Therapist强制先于Brain/Misleader任意；0不安目标不输出来源，多个Therapist同时间行为可完成。
