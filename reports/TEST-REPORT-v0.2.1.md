## 核查结论

- GitHub 与 Sites 的核心代码在修复前一致，主要差异为换行符和托管配置。
- 移动牌放地点是合法佯动，不应禁掉。原作者 FAQ Ca01/Ca02：https://main-bakafire.ssl-lolipop.jp/rooper/sr_game_02_rule.htm 。所有牌可放地点；只有暗跃相关效果能影响地点。
- 未复现地点移动牌导致规则引擎死锁。原线上存档已到第六张牌揭示且无活动租约；旧 UI 会在等待点击时显示对手正在行动，继续按钮又在棋盘下方，容易误认为卡死。
- 确认的问题：公共日程/打印及旧日志泄漏事件名；AI 使用原始日志且旧笔记可能沿用泄漏；模型 null 等异常输出缺少明确恢复路径；棋盘原先没有实体盖牌。
- 隐藏事件日程名称是本站按用户要求采用的可见性约定，不声称所有原版规则都将日程名称保密。发生后的公开效果仍保留，完整答案只供剧作家或终局复盘。
- 原始独立 tragedy-looper-design 目录未随现有仓库提供，本次依据 README、现有内容表、测试及官方 FAQ；不能声称已对照未取得的独立文档逐条验收。
