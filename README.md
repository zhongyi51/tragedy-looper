# 时隙 · 惨剧轮回模拟器

可本地运行的中文桌游模拟器：确定性规则引擎、DeepSeek 剧作家/主人公、独立席位观察、官方人物素材、音效、剧本编辑生成、自动存档、分支和离线回放。

v0.6 恢复原版公开事件日程，改进随机剧本的名称、时长与日期分布，加入四份原创精选剧本、真正的 AI 编剧、按席位组织的策略与结构化记忆，以及终局复盘和反馈。棋盘、手牌和结算动画沿用现有设计。v0.5 已加入 Mystery Circle（MC），v0.4 加入 Midnight Zone（MZ）及开局进阶自定义。

托管配置见 [DEPLOYMENT.md](DEPLOYMENT.md)。公开源码不携带 API 密钥、个人存档或私人站点配置。

## 启动

需要 Node.js 24 或更新版本。没有第三方 npm 依赖，不需要安装或构建步骤。

Windows 双击 `Start.cmd`，在本地终端隐藏输入 DeepSeek 密钥，或直接回车使用离线练习机器人。也可在项目目录运行：

```powershell
.\Start.ps1
# 完全离线，不询问密钥
.\Start.ps1 -Offline
```

打开 [本地游戏](http://127.0.0.1:4317)。启动脚本只把密钥保留在当前服务进程环境，退出后恢复原环境，不写入文件。也支持预先设置 DEEPSEEK_API_KEY 后执行 `node src/server.mjs`。不要把密钥添加到前端文件、导出文件或版本库。

服务仅绑定 127.0.0.1；默认端口 4317。存档和用量账本在 runtime/games.sqlite（SQLite WAL）。保留 runtime 目录和浏览器站点 Cookie 可继续自己的对局；备份 SQLite 时应先停止服务，或同时正确处理 WAL。

## 玩法与功能

- 档案室：选择立场（主人公 / 剧作家 / AI 观战）与剧本来源（官方 FS 教学剧本、精选剧本、快速随机、AI 编剧、工坊草稿）。四套集合各有一份原创精选剧本，附终局解锁的设计说明；存档列表显示轮回、日期与胜负，可随时继续。
- 棋盘：四个地点占满视口，人物卡随人数自动缩放，显示友好 / 不安 / 暗跃、不安临界警示、已确认角色、护卫与死亡。选中手牌后，合法目标高亮并预告效果（“→ 神社”“禁入医院”“不安 +1”“无效”）；盖放后不能撤回，六张牌齐后统一翻面，当天结算过的牌保留在目标上。
- 行动坞：底部固定显示“现在该谁做什么”、今日六张牌的进度、你的手牌或全部合法选项（按能力 / 人物分组，悬停高亮对应人物或地点）。主人公视角可点击席位预览另外两套手牌。数字键 1–9 选牌，Esc 取消。自己出的牌立刻落到棋盘上，可以马上选下一张，不等服务端也不等动画；服务端在后台按顺序确认，最后一张出完才等待结算。若某张牌没有确认成功，它会从棋盘上收回并提示重试，排在后面的不会再发送。
- 对手：建局时选择 DeepSeek 或离线练习机器人。默认开启“对手自动”，轮到对手时自动推进至你的回合；关闭后手动点“继续”，可随时暂停，已发送的一次调用仍会完成。“代走”让机器人替你走当前这一步。练习机器人是明确标识的离线启发式策略（剧作家对三张牌做组合前瞻，主人公只读公开信息），不冒充模型。
- 侧栏：情报（事件日程、已确认角色、生效中的规则标记、预算）、记录（按轮回、日期和阶段分组的公开日志，夹带 AI 主人公的公开理由；AI 剧作家的理由始终不展示）、推理（见下）、速查（当前惨剧集合的规则 Y / X、角色、事件）。手机上为抽屉。
- 结算播放：服务端为每一条结算结果返回一帧，界面逐条播放——谁出了牌、翻牌、每次移动、每个计数变化、被禁止的效果、能力、拒绝、事件、死亡——当前结果的人物或地点高亮，其余压暗，底栏显示这一步的说明和此前几步。可切换 1× / 2× 或“跳过”。每天结束时停在“第 N 日结束”，列出当天的死亡、事件与身份揭示，由玩家点“进入第 N+1 日”（或回车）；轮回失败时停在失败横幅。AI 观战时自动继续。被禁止、互相抵消（同一天两张暗跃禁止）或被无视的牌会在人物上盖一枚印记，牌面划掉并保留到当天结束；轮回失败、主人公胜利、剧作家胜利各有不同的全屏演出，棋盘随之变色。系统开启“减少动态效果”时仍逐条显示，只是不做位移动画。终局后可“揭晓真相”查看配役与事件；“终局复盘”列出实际规则、关键线索、作者设计与反制思路，可评价有趣、偏易、偏难、线索不足或重复感强。设计说明是复盘材料，不是最优走法证明。
- 推理表：主人公专用，只存在本浏览器。用“排除 / 认定 / 存疑”三种标记填人物 × 角色表和规则 Y / X；表头显示每个角色在仍可能的规则组合里的人数范围，已公开的身份、拒绝或接受过能力的人物、规则里没有的角色、人数已满的角色会自动填好并锁定。“推论”列出只剩一种可能的格子，可一键采纳；标记互相矛盾时给出提示。可为每个事件猜犯人，猜测会以标签显示在棋盘人物上；最后的战斗里，你认定和排除的角色直接标在选项上。另有按轮回整理的线索时间线（标出每条线索发生在第几日的哪个阶段）与自由笔记。轮回失败时，横幅、时之狭间和线索里都写明失败发生的时间与公开事实——某人一死轮回立即结束，或最后一天结束时失败条件成立及当时场上的暗跃；按规则，背后的规则和角色不公布，要靠这些线索推理。
- 规则手册：五分钟上手、行动牌、24 名人物（原始卡面与中文能力）、FS / BTX / MZ / MC 的全部规则 Y / X、角色与事件。
- 剧本工坊：快速随机、AI 编剧和 AI 润色分开。随机生成可换一份或锁定种子复现；AI 编剧设计规则、配役和事件，润色只改标题与简介。可视化表单编辑配役、角色、事件与犯人，显示角色配额与结构校验，也可直接改 JSON；支持 JSON 导入导出、公开 / 私密打印及以草稿开局。工坊会显示完整真相，主人公应从新对局里的 AI 编剧盲开局。
- 回放：单步、拖动、自动播放、方向键；公开或终局全解答视角；导出 JSON 或独立 HTML 离线回放（不需要服务、网络或 API，使用文字棋盘而非嵌入全部立绘）。
- 分支：终局后可从回放的历史位置创建新对局，再作不同选择；新分支有独立预算。

本地人类主人公控制三套牌；AI 主人公仍使用三个独立请求视角。它们保存引用公开日志的结构化假说、目标与疑问，并按本局讨论设置共享允许共享的笔记：只在轮回间讨论时，不把本轮新笔记即时传给队友。剧作家记忆始终独立。当前没有远程联机、好友邀请或语音聊天。

## 规则范围

基线为日文 5th 的 First Steps 与 Basic Tragedy Χ，包含24名基础人物、14种不同角色、16项规则 Y / X、9类事件和双方基础牌组。原始卡面和中文能力可在规则手册中查看。新增 Midnight Zone（MZ）：5 条规则 Y、7 条规则 X、14 种角色（含普通人）、11 种事件，包含 EX 卡、忍者伪装、预言者、伪装事件与最后的战斗。人工智能人物本就在日文第 5 版基础人物中，现在可在新局里保证出演。新增 Mystery Circle（MC）：5 条规则 Y、7 条规则 X、14 种角色（含普通人）、11 种事件，包含 EX 计数、双子的对角事件、治疗师与滴毒者的强制能力、地点封锁、移动限制及银色子弹提前结束轮回。两套集合均使用现有 24 名人物，可保证人工智能出演；其他惨剧集合、额外 11 名扩展人物和自定义特殊规则尚未启用。

MC 统一依据原作者公开的 Mystery Circle 速览（summary_002.pdf）及现行通用裁定，英文 Midnight Circle 规则书仅作比对。官方现行目录把该下载归于 MCΧ，而 PDF 标题为 MC；因此这里的 MC 名称不表示逐字复刻某一印次的英文盒规则。黑之学园的失败门槛为“学校暗跃 ≥ 当前轮回数 − 1”，所以第一轮必败；伪装自杀阻止主人公向 EX 人物盖所有行动牌；猎奇杀人实际发生即令 EX 增加 2，人工智能的效果模拟不计作事件发生。英文资料的部分措辞存在差异，详见本轮规则核验报告。

FS 没有最后的战斗；BTX / MZ / MC 最后指认逐人进行，首次错误即失败。模型只能选择引擎提供的候选编号，不能改变配役、犯人、计数器或胜负。没有合法效果的事件与没有发生的事件分别处理。

## 开局进阶自定义

新对局弹窗保留简洁默认项。快速随机和 AI 编剧都支持 FS / BTX / MZ / MC、短局 / 标准 / 长局；未手动指定时，生成器按所选时长安排天数、轮回与事件密度，事件日期不再固定在第 2 天与最后一天。进阶自定义可指定天数、轮回数、规则 Y / X（每项均可随机）、人物池、保证人工智能出演、事件数与种子。手动约束优先，切换集合不会把上一集合未修改的默认值误当成新约束。

标准开局公开事件名称与日期，犯人、角色配役和所选规则仍保密。MC 的愚者、双子与绝对者必须分别拥有至少一个犯人日程，私家侦探不能是犯人；不兼容的明确设置会提示错误。

普通盲开局不向前端暴露随机种子；服务器使用系统随机源，公开剧本 ID 也不含种子。手动填写种子是明确的复现功能，熟悉生成器的人可由它重建答案，因此不作为防作弊手段。随机剧本与 AI 剧本均在服务器创建，主人公只收到公开投影。

AI 编剧独立设计完整剧本和私密设计说明，必须通过现有规则、用户约束与静态质量检查才会开局。普通格式/设计错误最多修订一次；配役人数或日期错误在冻结已合法配置后最多修订两次。机制合法后，独立依据本稿实际规则核对设计说明；公开题名与简介另由不读取秘密配役的中性规则生成，避免模型文案暗示谜底；总计最多 4 次请求、180 秒，仍共用 $0.12 上限。任何阶段失败都不创建对局，可重新尝试或选精选剧本。真实调用仍观察到配额、犯人和说明错误导致拒稿，尤其是 MC 的自由编剧；界面将其标为试作剧本。该功能尚不能保证一次生成成功或达到原版剧本的平衡与可玩性。通过后的剧本随对局存档固定，跨轮回不修改犯人和真相；模型生成不是算法种子的确定性重放。

MZ 的“已宣告身份”可能来自忍者伪装，EX 也会改变角色；推理表保留手动记录，不据此自动锁死真实身份或套用基础集合的角色配额。

## AI 与预算

使用官方 `https://api.deepseek.com`，默认模型为 `deepseek-flash`。三牌计划、最后的战斗和候选较多的能力选择使用思考模式，其余选择采用快速模式；无需选择的结算仍完全由规则引擎处理。每次只发送当前惨剧集合的全部可能规则与出演人物，不按秘密的实际配役裁剪。服务记录原始 prompt/cache/completion token 用量；供应商缓存命中是尽力而为，不保证命中。

模型收到按席位生成的局势简报、有限搜索得到的候选参考以及公开证据。参考走法明确标为启发式，可能漏算，不是必胜证明；主人公侧不读取秘密配役，剧作家读取实际配役与事件，模型创作说明不进入任何席位的决策输入。对抗策略分别考虑即时威胁、常见反制、信息收益及最后的战斗。

每局默认预算 $0.50，可在建局时设置 $0.01–$10。请求前按 UTF-8 输入字节上界和最大输出预留，结束后按用量结算估算；超时可能已计费，保留预留且不自动重试。JSON/候选错误最多修复一次，仍失败则暂停。费用明细在终局开放，避免从秘密决策调用数量推断角色。AI 编剧每次另设 $0.12 估算上限，润色上限 $0.03，不与对局预算混淆。开局请求带有独立标识，重复恢复同一请求不会再次编剧；参数改变后使用新请求。

UI 的金额为保守费率估算，不是供应商结算账单；当前费率假设为每百万 token 普通输入 $0.30、缓存读取 $0.006、输出 $1.20。正式计费以自己的 DeepSeek 账户为准。用量和测试报告可以复核估算，没有把订阅额度当作 API 余额。

## 规则与交互约定

- 标准日程从开局公开名称与日期；事件阶段再宣布发生与否，即使发生后没有实际效果，也不自动揭示犯人。MZ 伪装事件只显示其公开名称；告白等明确要求揭示的效果照常处理。未设置可见性的剧本按原版公开；明确标记 hidden 的旧存档和自定义剧本保留原意，其人工智能能力先选一天、再声明目标、最后处理拒绝。公开 JSON、打印、回放和主人公 AI 遵守同一边界。原版依据见报告中的官方 Masterbook 与规则书链接。
- 所有行动牌都可盖在地点上；地点只接受暗跃相关效果，移动、友好、不安等牌是无效果佯动。依据[原作者 FAQ Ca01 / Ca02](https://main-bakafire.ssl-lolipop.jp/rooper/sr_game_02_rule.htm)。不将合法佯动误判为非法动作。
- 牌背直接落在棋盘目标上，标明幕 / A / B / C。六张齐后统一翻牌，动画结束后继续推进；减少运动模式和动画异常不阻断规则操作。
- AI 只能返回当前合法候选的整数编号，服务器检查结构、候选和当前局面。格式错误最多修复一次；网络不确定性不自动重试，出错保留局面并展示可恢复提示。

## v0.2.2 自动结算与连接恢复

- 每次行动提交后，服务器连续执行不需要选择的规则步骤。移动、计数器、强制能力与无目标选择的事件不再逐项等待 AI。真实的可选能力、拒绝、事件目标及会影响结果的邪教徒选择仍由对应席位决定。
- `/advance` 只执行确定性规则，不发送模型请求。可恢复停在旧版结算阶段的存档；到达真实决策边界时停止。所有中间规则步骤仍保存为回放快照，前端依次展示可见变化。
- 接口响应先检查 HTTP 状态、重定向和内容类型。登录页面、网关 HTML、损坏 JSON 与网络中断不再直接显示 JavaScript 解析错误；行动结果不确定时先读取当前存档，不自动重发行动或付费请求。
- Sites 登录失效时使用平台的顶层登录入口，返回后恢复已保存的对局。浏览器不持有模型 API 密钥，不绕过站点访问权限。

## 体验更新：AI 强度与界面

- 每次 AI 决策附带按席位生成的局势简报（`strategicBriefing`）：剧作家看到各事件犯人的不安差距、关键人物、杀手同处与移动建议；主人公只看到公开计数器、事件日程与已确认信息；反事实测试检查提示和参考走法不依赖秘密配役。
- 模型输出解析容忍代码块和前后杂讯，只接受 JSON 对象；仍无法解析才进入一次修复流程。

## v0.3 界面与对手

- 前端不再是单个脚本：渲染函数只返回 HTML 字符串，会话控制器与演出控制器的依赖（请求、存储、DOM 效果）全部注入，因此界面逻辑由 `node --test` 直接导入模块验证，不依赖浏览器。页面按区域比对 HTML 后才替换，输入焦点与光标不丢失。
- AI 剧作家在每天开始出牌时一次请求给出最多三张牌（仍然只能返回互不相同的合法候选编号，服务器逐张校验后依次执行，格式不符进入一次修复），并附带离线搜索给出的参考组合。人类主人公一人操控三套牌，因此以团队视角看到三套手牌和自己盖下的牌面；AI 主人公仍是三个独立视角。
- 视图新增公开的规则标记（主人公不死、住院患者可离开医院、被压制的事件），客户端不再从日志文本推断；进入最后的战斗时清空当日盖牌。
- 存档列表由服务器给出摘要（标题、轮回、日期、胜负），终局前不返回花费。
- v0.3 历史离线机器人基线：200 局中剧作家 136 胜、主人公 64 胜；这是旧版本的可推进性记录，不作为 v0.6 棋力或剧本平衡结论。
