# 时隙 · 惨剧轮回模拟器

可本地运行的中文桌游模拟器：确定性规则引擎、DeepSeek 剧作家/主人公、独立席位观察、官方人物素材、音效、剧本编辑生成、自动存档、分支和离线回放。

v0.2 提供 ChatGPT Sites 私有托管适配（Worker + D1），以及更完整的交互反馈、移动/计数/轮回动效、键盘焦点管理和小屏布局。托管配置见 [DEPLOYMENT.md](DEPLOYMENT.md)。公开源码不携带 API 密钥、个人存档或私人站点配置。

## 启动

需要 Node.js 24 或更新版本。没有第三方 npm 依赖，不需要安装或构建步骤。

Windows 双击 `Start.cmd`，在本地终端隐藏输入 DeepSeek 密钥，或直接回车使用离线练习机器人。也可在项目目录运行：

```powershell
.\Start.ps1
# 完全离线，不询问密钥
.\Start.ps1 -Offline
```

打开 [本地游戏](http://127.0.0.1:4317)。启动脚本只把密钥保留在当前服务进程环境，退出后恢复原环境，不写入文件。也支持预先设置 DEEPSEEK_API_KEY 后执行 `node src/server.mjs`。不要把密钥添加到前端文件、导出文件或版本库。

服务仅绑定 127.0.0.1；默认端口 4317。存档和用量账本在 runtime/games.sqlite（SQLite WAL）。保留 runtime 目录和浏览器站点 Cookie 可继续自己的对局；备份 SQLite 时应先停止服务，或同时正确处理 WAL。

## 玩法与功能

- 档案室：开始官方 FS 教学剧本或新生成的 FS/BTX 剧本，选择主人公、剧作家、AI 观战；继续自动存档。
- 棋盘：选择手牌后点击人物或地点。盖放后不允许撤回；双方牌面统一揭示。能力阶段从合法候选选择目标，强制事件由规则引擎处理。
- AI：点击“让 AI 推进至我的回合”；观战模式会继续到终局或暂停。可随时停止自动推进，已发送的一次调用仍会完成。练习机器人是独立、明确标识的低强度离线策略，不冒充模型。
- 剧本工坊：可复现种子的约束生成、AI 标题/简介润色、完整 JSON 编辑、结构验证、JSON 导入导出、公开/私密打印 HTML 页。
- 回放：单步与拖动、公开或终局全解答 JSON、导出独立 HTML 离线回放。离线 HTML 不需要运行服务、网络或 API；为了便携，使用文字棋盘而非嵌入全部立绘。
- 分支：终局后可从回放的历史位置创建新对局，再作不同选择；新分支有独立预算。

本地人类主人公控制三套牌；AI 主人公为三个独立笔记和请求视角。当前版本没有远程联机、好友邀请或语音聊天。房间有交流规则字段，AI 默认各自决策，尚未加入轮回间自动讨论模型；不影响规则流程，但限制协作强度。

## 规则范围

基线为日文 5th 的 First Steps 与 Basic Tragedy Χ，包含24名基础人物、14种不同角色、16项主副规则、9类事件和双方基础牌组。原始卡面和中文能力可在规则手册中查看。扩展集合、额外11名扩展人物和自定义特殊规则未启用，导入时会拒绝不支持的规则。

FS 没有最后的战斗；BTX 最后指认逐人进行，首次错误即失败。模型只能选择引擎提供的候选编号，不能改变配役、犯人、计数器或胜负。没有合法效果的事件与没有发生的事件分别处理。

## AI 与预算

使用官方 `https://api.deepseek.com` 和 `deepseek-flash`，非思考模式进行低成本决策。固定规则形成稳定前缀，服务记录原始 prompt/cache/completion token 用量；供应商缓存命中是尽力而为，不保证命中。

每局默认预算 $0.50，可在建局时设置 $0.01–$10。请求前按 UTF-8 输入字节上界和最大输出预留，结束后按用量结算估算；超时可能已计费，保留预留且不自动重试。JSON/候选错误最多修复一次，仍失败则暂停。费用明细在终局开放，避免从秘密决策调用数量推断角色。

UI 的金额为保守费率估算，不是供应商结算账单；当前费率假设为每百万 token 普通输入 $0.30、缓存读取 $0.006、输出 $1.20。正式计费以自己的 DeepSeek 账户为准。用量和测试报告可以复核估算，没有把订阅额度当作 API 余额。

## 测试

```powershell
node scripts/test-all.mjs
# 上述命令自动启动隔离服务，运行全部 53 项测试，不调用真实模型。
node --test test/engine.test.mjs
# 先启动服务，再运行接口测试
node --test test/http.test.mjs
# 服务启动后也可直接运行全部自动化测试（不产生模型调用）
node --test test/*.test.mjs
# 使用已经配置密钥的本地服务，会产生真实 API 用量
node test/live.mjs
$env:TEST_SET='BTX'
node test/live.mjs
```

扩展验证见 [v0.2 测试报告](reports/TEST-REPORT-v0.2.md)，包括 400 局随机流程测试；[v0.1 测试报告](reports/TEST-REPORT.md)记录此前真实 DeepSeek 整局用量。脚本生成“结构合法”并不保证平衡；正式发行前仍需要玩家试玩和独立规则复审，不声称已通过所有扩展或比赛级反作弊认证。

## 文件结构

| 路径 | 职责 |
| --- | --- |
| src/content.mjs / data/catalog.json | 内容、配役验证、约束生成 |
| src/engine.mjs | 纯状态机、合法动作、裁定与观察投影 |
| src/ai.mjs | DeepSeek、候选编号、缓存前缀、用量与恢复 |
| src/server.mjs | 本机 API、会话权限、SQLite 事务、回放与导出 |
| public/ | 响应式棋盘、工坊、回放、音效交互 |
| assets/ | 已授权原始人物图片、卡面与 CC0 音效 |
| test/ | 自动化规则、接口与真实模型测试 |
| worker/ / drizzle/ / scripts/ | 私有托管适配、数据库迁移、构建及隔离测试 |
| runtime/ | 本机私密存档；不包含在分发包内 |
